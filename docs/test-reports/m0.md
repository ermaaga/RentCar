## 2. Failures found and fixed during M0

- Vulnerable `minimatch` in the dev toolchain (GHSA-g3hv-75wg-m249): fixed by a pnpm override.
- npm and its bundled packages in the runtime image carried HIGH and CRITICAL findings: removed from the runtime image.
- Border token failed WCAG 1.4.11 (3:1): darkened in both themes.
- CSS token duplication above the jscpd threshold: the dark theme needs two selectors, so `tokens.css` is excluded from jscpd with that reason written in `.jscpd.json`.
- A TypeScript-only construct in a `.mjs` file and a `.then` on an untyped module: caught by the type checker and rewritten.
