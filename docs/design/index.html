RentCar: three visual directions

Same screens, same flows (from the UX document), three different looks. Each direction defines the platform default theme and is shown with two tenant palettes (a calm blue and a deliberately tricky bright yellow) in light and dark mode. Open the mockups in a browser; use the selectors on top of each page to switch tenant and mode. Mockups are prototypes for deciding, not production code.

Design principles for this project (priority order)

  1. Thumb first, glance fast. Main actions in thumb reach, targets at least 44 px, one primary action per screen. Verified: no horizontal scroll outside the calendar at 375 and 320 px.
  2. Any tenant palette stays readable. Components use semantic tokens only; hover, disabled and on-colour variants are derived; status colours are fixed by the platform and never themed.
  3. Never colour alone. Every status is icon + text (+ pattern or border in the calendar).
  4. Trust before polish (customers). Total price visible early, "Nothing was charged" repeated, booking code large, no marketing noise.
  5. Legible in sunlight and in the dark. Contrast at least 4.5:1 for text everywhere (7:1 for the Field direction); dark mode is calibrated, never pure black.

Field

High contrast, big targets, built for the counter and the car park

Best if staff at the counter or in the car park are the main buyers and sunlight, gloves and interruptions are the daily reality.

Warm

Friendly, photo-led, travel-first

Best if the tenants sell on experience (tourist areas) and have good vehicle photos.

Recommendation: Clear, borrowing two things from Field (large time numerals and 48 px targets on the Today screen; a 3 px focus ring with offset) and one from Warm (friendlier confirmation microcopy). Reasons in docs/04b-ui-design.md, section "Visual directions".

Mockup notes: typefaces load from Google Fonts only for these mockups (the product self-hosts them; with no network the pages fall back to the system font). Vehicle photos are placeholders. Plain CSS variables named like shadcn tokens are used instead of the Tailwind CDN.
